# 試作UI タスクリスト

この一覧は、次の試作画面を改善する項目をまとめる。ゲーム本編の設計・コード実装とは分け、完了条件を満たした項目にチェックを入れる。

## 画面構成と閲覧

- [x] 証拠品・ログと同じタブ領域に「判明事項」を追加する。
  - 判明事項を捜査報告書のように一覧し、項目を選ぶと内容を読み返せる。
  - 確認操作は既に得た情報の閲覧のみとし、新しい情報や進行状態を発生させない。
- [x] 人物一覧を2列にし、人物アイコンを現状より大きくする。アイコンの下に名前を表示する。
- [x] 画面内の人物・証拠品など、すべてのアイコン表示枠を正方形に統一する。

## 捜査操作

- [x] 証拠品を選んで調べる操作を、会話ダイアログに似た選択式の流れにする。
  - 調べる対象・選択肢を一つずつ提示し、選んだ対象の結果を表示する。
  - 調査済みの対象と結果を保持し、画面を再読み込みしても状態を復元する。
- [x] 操作名を対象の種類に合わせる。
  - 人物：「話をする」
  - 証拠品：「証拠品を調べる」
  - ログ：「ログを解析する」
  - 判明事項：「判明事項を確認する」
  - 「判明事項を確認する」は閲覧操作として扱う。

## 表記とフォント

- [x] 黒田の表示名を「黒田恒一」に統一する。
- [x] イニシャルは姓・名の順にする。例：黒田恒一は「KK」。英語でフルネームを表記する場合も姓、名の順にする。
- [x] ログにはサイバー捜査の雰囲気に合う等幅系フォントを使う。
- [x] 使用するすべてのフォントについて、商用利用可能かつクレジット表記不要であることを確認する。フォントファイルとライセンス情報をリポジトリに保管し、表示に使う書体をその範囲に限定する。

## 追加フィードバック

- [ ] ログビューワの書体をNoto Sans MonoからShare Tech Monoに変更する。
  - [x] Google Fonts公式メタデータでShare Tech MonoがSIL Open Font License 1.1であることを確認。商用ソフトへの同梱・販売は可能。画面上の作者クレジットは要求されないが、再配布時は著作権表示とライセンス本文をフォントと一緒に含める。
- [ ] 下部のセリフ用ペインを常時表示する。
- [ ] 証拠品の調査選択肢を、一般的なノベル型ADVの会話中の選択肢と同じ画面内表示にする。選択肢表示中に背景画面をぼかしたり暗くしたりしない。
- [ ] 証拠品調査を中止するボタンを選択肢の下に同じ並びで配置し、表示文言は「やめる」とする。
- [ ] 資料タブを選択中でも、人物を選択したらメインペインをその人物の画面に切り替える。

## 他の端末からの試作体験
