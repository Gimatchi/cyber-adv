# Case 001変更案の扱い（決定）

**位置づけ:** 2026-10-15作成のCase 001変更案に対する決定記録。旧変更案は採用しない。  
**決定日:** 2026-10-20

## 決定

- Case 001の人物設定、事件設定、物語、シナリオデータは変更しない。
- 地下アイドルへのストーカー行為を背景とするSNS乗っ取り事件は、Case 002として新規作成する。
- Case 001変更案に書かれていた人物関係・動機・捜査方針の見直しは、Case 001には適用しない。Case 002の制作では、Case 002用の資料を基準にする。
- 共通エンジンや再利用可能なデータ・素材・調査グラフは、Case 001側を変更せず、必要なものだけCase 002へ参照・移植する。
