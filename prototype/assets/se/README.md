# 効果音ファイル対照表

| 元の素材名 | 追加前のファイル名 | リネーム後のファイル名 | 用途 |
|---|---|---|---|
| 決定ボタンを押す3 | `click03.mp3` | `click.mp3` | 一覧・資料タブ・メニュー開閉などの一般操作 |
| 決定ボタンを押す4 | `click04.mp3` | `information-obtained.mp3` | Eventによって証拠品・ログ・判明事項を新たに取得したとき |
| カーソル移動11 | `cursor11.mp3` | `confirm.mp3` | 会話の選択肢、調査操作、ログ行などの決定 |
| キャンセル1 | `cancel01.mp3` | `cancel.mp3` | 会話やログ解析の終了、ダイアログの取消し、メニューを閉じたとき |
| ビープ音4 | `beep04.mp3` | `unavailable.mp3` | 現在選択できないログ行など、実行できない操作 |

効果音は `app.js` の共通 `playSound()` から再生します。ブラウザの自動再生制限などで再生できない場合は、ゲーム進行を止めずに無音で続行します。
